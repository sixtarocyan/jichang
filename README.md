# 好用机场推荐

## 自用机场整理 - 持续更新

用过一键连接的客户端，和机场流量订阅+第三方翻墙客户端两种方式。机场订阅+第三方翻墙客户端胜在可规则自定义，因此可以实现流量的分流，在不影响正常墙内软件和网页的使用下，可以使特定需要境外的流量外翻。个人使用windows，ios，Pados, macos，在这四种平台下，机场订阅+第三方翻墙客户端都丝滑无感，因此目前已经从一键连接客户端版本转移向机场梯子方法。

主流的第三方翻墙工具：

- [Clash verge rev](https://github.com/clash-verge-rev/clash-verge-rev)，支持 windows, macos, linux
- [Clash nyanpasu](https://github.com/libnyanpasu/clash-nyanpasu), windows, macos, linux
- Shadowrocket, 支持苹果系统，目前已经有 ios, pados, macos，可以使用一个境外的 apple ID，在 app store 下载
- 其他还包括 Surge, Hiddify, singbox，之类，但我没有试过，不同客户端支持的连接协议不同。


作为技术小白，做个比喻，我认为这些第三方客户端，就像是一个电视，然后机场订阅像是机顶盒，“电视”-第三方客户端负责万能播放，“机顶盒”-机场订阅负责决定你能播放什么。而那些一键连接的客户端就像是预装了电视节目的电视，可以实现打开电视就能看节目，但是缺少一点自主性，因为自己不能决定想看什么。


下面是我自己用过的一些机场和个人评价，（完全主观），持续寻找好用的工具，不定期汇总更新：
